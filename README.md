# Proyecto_final_visualizacion_grafica
Story teller, calidad del aire en Mexico
Autor: Julian Perez Ortega 

# Descripcion:
En este proyecto se utiliza un dataset que muestra los datos sobre la contaminacion del aire en mexico, en el cual se explicara cuales son realmete los verdaderos villanos de la historia.

Dataset principal: https://www.datos.gob.mx/dataset/calidad_aire_emisiones_contaminantes
Geojson mapa mexico: https://github.com/angelnmara/geojson/blob/master/mexicoHigh.json
Ambos descargados el 28 de abril, el dataset a la 1 pm y el geojson a las 2 pm

# Instrucciones main.py: 
Descargar las librerias en el archivo de requirements.txt y escribir python main.py en la terminal.

# instrucciones para desplegar tambien el sitio: 
Descargar las librerias en el archivo de requirements.txt, descargar quarto en internet e instalarlo en la ruta recomendada, instalar la extension 'quarto' en visual studio para que reconozca el archivo 'index.qmd', usar 'python main.py' en la terminal para generar las graficas, despues usar 'quarto render' en la terminal, y por ultimo ir al repositorio de github para ahi (Settings → Pages → Source → Deploy from branch → main → /docs → Save.) y el link de la pagina generada aparecera ahi mismo.
