# Proyecto_final_visualizacion_grafica
Story teller, calidad del aire en Mexico
Autor: Julian Perez Ortega 

Descripcion:En este proyecto se utiliza un dataset que muestra los datos sobre la contaminacion del aire en mexico, en el cual se explicara cuales son realmete los verdaderos villanos de la historia.

Dataset principal: https://www.datos.gob.mx/dataset/calidad_aire_emisiones_contaminantes
Geojson mapa mexico: https://github.com/angelnmara/geojson/blob/master/mexicoHigh.json
